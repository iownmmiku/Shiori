# 角色日程

从侧边栏的「自动化 → 角色日程」打开独立管理页。每个人格拥有自己的生活档案、周表、年度活动和日记；多个会话使用同一人格时共享基础日程，待回留言与真实聊天素材按会话分别处理。

## 开始使用

1. 在页面顶部选择人格与日期。
2. 点击「生成这一天」。初次会先分析角色档案、整理年度活动，再生成当天安排；进度直接显示在页面中。也可以先手动填写「角色与周表」，再生成当天。
3. 查看各时段的内容，按需要修改，保存。每天必须连续覆盖 `00:00～24:00`，跨午夜的活动拆成两段。时段可锁定，重新生成时保留锁定内容。
4. 用页面顶部的「角色日程总开关」开启功能，切换后立即保存，与「运行设置」中的开关同步。普通聊天只读取已经保存的当前日程，不会因为缺少安排而等待模型生成；未生成时照常聊天。

日程功能初始关闭。「根据日程控制回复」独立关闭；只开启角色日程时，模型获得当前活动作为扮演资料，回复不会被延后。本地网页聊天始终可用，不受忙碌状态阻挡。

## 空闲、半忙与忙碌

明确打开回复控制后，可选择作用于所有会话，或只作用于勾选的会话。选择部分会话但没有勾选时不控制聊天。已有 QQ 接收规则、管理员权限、静默设置继续生效。

- **空闲**：走普通聊天流程。
- **半忙**：在设定的时间窗口内收集留言，再交给普通聊天流程；新留言不会不断延长日程的慢回等待。时段可设置独立的慢回间隔。
- **忙碌**：先保存被直接唤醒的留言，恢复可联系后再处理。未唤醒机器人的群聊旁听消息不进入待回队列。

日程留言释放后继续使用原有的消息防抖、群聊多人统一回复、图片输入、权限判断及分段发送。每批最多包含八条原消息，较长的积压会分批处理。切换或修改人格、撤销会话权限、删除原消息后，旧留言不会交给其他角色或借用其他成员的权限。

命令和停止请求不因日程而被暂存；群成员只能取消自己的待回输入。队列有数量及保留时间限制，可在页面查看与清除，等待、处理中和待核对共同占用数量限额。全部回复确认送达后才结束这一批；部分失败或中断继续显示待核对。程序重启会保留尚未派发的留言；已经尝试但结果不明确时，核对实际聊天记录后再明确重试，避免重复消息。

开启「弹性联系」后，可根据同一会话的消息为个人休息安排有限延后，固定职责和锁定时段仍保留。额外判断在后台合并处理，并受冷却、日程调用额度和总模型预算限制。「提前告知」会把即将发生的活动提供给正常回复作为自然表达参考，不会凭空声称现实任务已经完成。

## 节庆、纪念日与编辑恢复

「节庆与纪念日」可以编辑年度节庆、休假、普通活动，以及按公历每年重复的生日和约定。重复规则支持跨年持续时间、起止年份和闰日策略。真实公共节日根据角色关联地区计算；同人和自创世界的日期应保留推定或公历映射说明。

日程生成和日记可以分别选择已有的对话模型，留空跟随默认模型。联网资料使用 Shiori 已配置的网页搜索服务，无需再填写一套搜索密钥。模型创作与检索参考会区分来源；公共日历并非所有职业、学校的权威校历。

手动保存档案、周表、日程、年度活动或重复规则前会保留编辑快照，可在「预演与撤销」中恢复。预演只读取指定日期和当地时间的安排，不调用模型、不发送消息，也不改变实际队列。

## 生活日记与真实记忆

生活日记属于虚构角色创作，单独保存，不自动写入用户长期记忆，不作为真实电脑操作或现实行动的回执。跨日归档只为已有日程的日期生成；模型失败保留已有篇目。

默认只按角色日程写日记。需要加入聊天素材时，单独开启素材采集，并明确勾选来源会话；空名单不采集。素材从开启后开始记录，不回读旧聊天。同一人格在不同来源会话的日记分别生成和查看，私聊内容不会合并到其他群或私聊的日记中，普通聊天上下文也不会自动引用这些日记。

素材、日记、生成任务、编辑快照和待回状态保存在独立数据目录中的数据库里，随正常数据库备份保存。关闭采集或移除来源会话会清理尚未归档的对应素材，已经生成的日记需要按页面中的来源查看。

清空某个会话的聊天记录时，也会清除该会话的待回留言、尚未归档素材，以及引用这些聊天的日记和其续篇；不引用聊天的纯日程日记继续保留。清空确认框会提示这个范围。原消息被删除或修改后，旧素材不再用于生成；生成过程中来源失效时丢弃结果，避免被删内容再次出现。底层不包含聊天的备份同样排除这些原话副本及相关日记，常规完整备份仍包含它们。

## 模型用量与故障

每日额外调用额度默认 12 次；档案、年度活动、每日安排、日记和弹性判断均计入，首次分析可能使用多次调用。设置为 0 会停止模型生成，手动编辑仍可使用。用量以配置时区跨日，同时遵守 Shiori 的总 Token/费用预算。达到限额后保留现有安排，页面说明失败原因，不会为了聊天反复重试生成。

生成任务显示阶段和已保存步骤，可以停止；进程退出后的任务标为中断，不自动重复调用。再次生成时复用有效步骤。手动编辑、切换人格或撤销设置时，旧任务的结果会被丢弃，避免覆盖新的安排。
