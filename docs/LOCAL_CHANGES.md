本文件按阶段保留0.1.1开发时的本地修复、当时未发布状态及验收记录。正式发行下载见[GitHub Releases](https://github.com/iownmmiku/mikubot/releases/tag/v0.1.1)，发行验收见[测试报告](../TEST_REPORT.md)。

基于已发布的0.1.0，此前补修保持版本不变；现按用户要求增加GitHub更新功能，本地版本设为0.1.1。本次只修改本地源码，没有提交、推送、打标签、发布或重建安装包。GitHub原有安装包和源码ZIP仍为此前构建。

## 人格与统一配置

- 人格创建支持“按描述直接生成”“作品角色蒸馏”“已有语料蒸馏”。直接生成不搜索、不输出Skill；角色蒸馏保留来源确认与Skill；语料模式只输出人设。均先预览、试聊，再显式保存。
- 可复用机器人配置统一选择人格、聊天模型、触发规则、群聊方式与工具能力，新会话继承默认配置。
- 旧会话保留原有覆盖；“绑定聊天”可批量迁入配置，清除配置覆盖，保留聊天、记忆和共享空间。人格与配置绑定不等于记忆共享。
- 默认仅初音未来；设为默认人格修改默认配置，不再只改当前会话。

## 模型、QQ与管理员上手

- 快速入门提供DeepSeek、OpenAI、Ollama、SiliconFlow和自定义模板，选模型后“测试并用于聊天”，测试成功才自动绑定默认聊天模型。失败保留原路由，短文本测试可能计费。从服务实际返回的目录中推荐并预选聊天型号，保留有效的用户选择；DeepSeek补齐预设型号。改地址或密钥立即清除旧目录，延迟返回也不能恢复旧推荐。推荐不证明工具/图片能力或费用。
- QQ连通性自检覆盖实际连接、认证、标准管理端口、只读OneBot API Echo、消息上报与最近处理阶段。端口有响应不代表QQ已登录；离线不能确认Token是否错误时显示未检测，不猜测成功。
- 60秒快速管理员配对：在管理台开启，持码的目标账号通过真实私聊入口绑定该实例，单次使用、过期失效；保留人工核对模式。允许聊天名单不批量提权。
- 逐步确认模式支持原会话“同意/确认/拒绝”，仅同一签名管理员、同一会话的唯一待审批动作生效，5分钟过期，多任务歧义保留完整编号与审批码。自动执行模式不额外要求确认。

## 记忆与排障

- 旧记忆缺失字段、异常评分使用保守默认值，保留版本历史。聊天只查询少量偏好，不生成完整画像摘要；画像页面也已下推SQL分页，每页最多50个候选，再校验可见性、共享、时效与依赖。API不构造摘要，显式内部摘要最长2万字。
- 历史引用、使用记录只查询相关记忆与依赖闭包，避免每条历史消息重建全份可见投影。一般词法/向量检索仍按会话读取有效候选；快照读取、分词与词法排序移至后台线程，最多2个并行、32个含运行中的待处理请求，取消仍等待实际计算结束才释放名额。返回前重新检查当前可见性与版本。最终权限投影、关系和向量缓存维护仍有同步计算，不能将偏好查询基准当全链路耗时。
- 去除自然聊天强制附带“记忆ID前8位”的指令。保存与分段前清理已知内部记忆引用，历史回复也按来源元数据清理；后台来源与版本保留。代码、链接、未知编号和用户明确输入的示例保留。
- 异常记录错误编号和脱敏堆栈；后台任务失败也记录可搜索的任务编号与堆栈。运行日志按5MB轮转，保留3份。独立桥接器没有脱敏器时只保存位置与异常类型。
- OneBot收到单次坏JSON帧不再立即掉线；连续3次坏帧会关闭异常连接。已有消息去重、连接替换、心跳和发送结果检查继续生效。
- 前端使用独立于公开版本号的资源内容摘要刷新缓存，入口不缓存、静态资源重新验证；同版本本地修复后不再持续加载旧脚本。

## 隔离与远程访问

- 新安装默认选择Docker隔离代码执行，电脑能力默认关闭；原有本机配置不强制迁移。本机模式清楚标明当前账户权限，工作目录不是沙箱。
- Docker仅使用本机Linux引擎与预先准备的`python:3.12-slim`，断网、非root、只读系统、移除capabilities、禁止新权限、限制CPU/内存/进程数，仅映射专用工作目录与本次只读脚本。不可用时停止，不自动下载或降级。
- 拒绝挂载管理数据目录、磁盘根目录及含链接/联接的工作目录。文件工具由宿主执行且检查路径，MCP不被代码容器隔离；Docker电脑能力开启时默认阻止MCP调用，包含已等待审批的动作。高级设置可明确允许沙箱外MCP，仍检查管理员及工具允许列表。容器仍依赖宿主内核与Docker引擎安全。
- 远程管理默认要求HTTPS，明文登录也拒绝。界面生成Caddy配置并支持填写域名；只有可信TCP代理与配置Host匹配时接受HTTPS转发头。显式代理IP只用于传输判断，不授予本机初始化权限。
- 可信局域网原始HTTP须明确选择；不会自动申请证书、开放防火墙或把域名连通性写成成功。

## 恢复、桌面与部署

- 托盘加入本机密码重置，CLI提供`--reset-password`。旧会话失效，聊天记忆保留，无HTTP重置接口；手动删除专用密码文件恢复方式继续支持。
- 桌面组件缺失或加载失败自动回退默认浏览器，尝试发送非模态托盘通知，通知不可用时记录日志并继续运行；先停止原服务、释放锁，避免双实例。
- 蒸馏保存分阶段检查点，重启后可手动续作，复用已完成分析和来源快照，保留累计预算；模型、材料或参数变化拒绝旧缓存。重复续作沿用同一原任务正在运行的续作。未知请求结果可能重发计费；不重放电脑命令。
- 核心迁到`shiori`；`qunyu`兼容入口映射同一模块对象，数据库名和原数据不变。启动、构建与源码白名单同步。
- 支持Python3.11–3.13。无头依赖与Windows桌面依赖拆开，Linux脚本、非root只读Dockerfile与持久卷Compose就绪；无头首次设密使用`--init-password`。
- 可调每模型并发、模型/后台/每会话队列容量，前台优先、排队满时明确拒绝。SQLite继续使用WAL与单实例保护，没有引入共享目录多节点写入。取消排队请求及时清理占位，避免队列积累。新增本地8线程、8会话、160次并发记忆写入检查，全部记录保留；不代表真实QQ压力验收。
