## 新增功能

- 独立嵌入模型：在“模型供应商 → 嵌入模型”复用或新增连接，获取型号、专用接口测试并启用记忆检索；失败保留原选择，独立类型不混入聊天选择。旧配置兼容，使用步骤见[指南](USER_GUIDE.md#嵌入模型与语义检索)。

- 生成时分段：默认由模型首轮用空行确定独立消息，不按目标字数补切；单换行、完整代码/JSON保留，本地聊天显示已存边界，旧长度模式仅供主动选择兼容。见[说明](MODEL_OUTPUT.md)。

- 本地插件：界面新建、编辑、启停、删除和运行；本地聊天通过工具生成草稿、查询与运行。子进程复用电脑权限，改变修订或配置会撤销任务；不加载代码到服务进程，不自动安装依赖。见[插件说明](PLUGINS.md)。
- Windows 安装版一键更新：由本机用户选择版本，下载校验后退出、静默安装、沿用数据目录重新打开；失败记录保存在数据目录。源码和便携部署保持手动，不覆盖开发目录。见[更新说明](UPDATES.md)。
- 数据统计：1/3/7天消息与Token趋势、平台分布、模型记录、CPU/内存/运行时间；SQL聚合不读取全部消息正文。未采集首字延迟、未知价格会明确显示。
- 模型故障：使用预算、超时、中断、限流的独立异常类型，默认90秒并允许5—600秒配置；超时文案中的“预算估算”不再触发额度不足提示，不确定消费不自动重试。

## 使用上的边界

0.1.3发行核对：整合嵌入入口后Python3.12完整回归1217通过、2跳过；前序阶段Python3.11/3.13整改相关回归各105项、随后模型分段相关回归各58项通过，最终跨平台结果由对应提交的CI记录。实际EXE嵌入配置、插件子进程、真实安装器自动更新并重启桌面、0.1.2升级与数据保留通过。更详细的验证对象与未覆盖项见[测试报告](../TEST_REPORT.md)。

SQLite仍是单进程写入，独占保护不等于支持共享数据库集群或网络文件系统。所有实例均退出后才可处理失效锁：同宿主/命名空间可证明PID不存在时自动清理；外来或损坏标记保守拒绝，需要核对后手动移除 `.instance-owner.json`。不要为启动第二个写入者删锁。

时区设置当前用于日统计、配额、安静时段和人格探索；原有自然语言提醒解析及部分聊天时间文案仍沿用UTC+8，不应把日配额设置当作提醒时区迁移。

自动更新的 SHA-256 是发行文件完整性校验，不是独立代码签名；安装器已有分阶段写入与失败恢复，不包含新进程启动健康失败后的整套数据库回滚。开发阶段用隔离安装器替身验证成功/失败分支，0.1.3发行核对另用真实冻结安装器验证静默安装与重启，详情以测试报告为准。真实QQ、收费模型、长时间挂机、当前固定镜像的本机Docker运行均不在本轮本机验收结论内。
