# Shiori 0.1.6 预发布

本次以 **Pre-release** 交付，不设为最新稳定版；程序版本为0.1.6，正式稳定版仍为0.1.5。变更范围较大，建议先备份，在测试实例试用后反馈。

## 主要更新

- 增加可配置消息防抖：等待期间收集连续消息后统一回复，支持全局、机器人配置和单会话继承，默认关闭。
- 统一消息时间来源与相对日期处理，区分平台发送、程序接收和历史录入时间，改进时间回忆及提醒。
- 将供应商、对话和嵌入模型集中到“机器人配置 → 模型”；整合高级生成参数配置（社区PR #8）。
- 规范ZIP、tar.gz、tgz插件包导入，支持辅助模块、资源、修订、回退与导出；本地聊天可读取并修改已有插件，保存后仍需检查并启用。
- 整合可自定义分组、排序、图标和显隐的侧边栏（社区PR #11），修复改名交互、异常布局与较新布局存档保护。
- 记忆档案默认显示全部会话并标注来源，支持切换当前聊天；不改变实际召回的隔离规则。
- 改进对话衔接、时间召回、摘要与历史提取游标；修复工具定义未计入输入预算、参考附件末尾丢失和Wiki角色作品核验。
- 修复大记忆库中历史校验与来源图重复遍历导致的本地等待，补充各阶段耗时记录；修复草稿、附件与连续命令处理问题。

感谢[HuangGuaKnn](https://github.com/HuangGuaKnn)贡献高级模型参数、自定义侧边栏及历史管线审计材料。

## 下载与升级

- Windows安装版：`shiori-0.1.6-Windows-Setup.exe`。
- Windows便携版：完整解压`shiori-0.1.6-Windows-x64.zip`，不要只提取EXE。
- 源码：`shiori-0.1.6-source.zip`，支持Python 3.11–3.13，推荐3.12。

0.1.5可在右上角“版本与更新”开启**显示测试版**，再选择0.1.6。此开关默认关闭，常规稳定版检查不会推荐本预发布。0.1.3/0.1.4安装版需按原流程完成首次升级；Docker仍通过镜像更新。

升级前退出旧实例，另存完整数据目录、原始材料、插件与电脑工作目录。不要让新旧实例同时写同一数据目录；源码有本地修改时不会自动覆盖。回退前核对数据库兼容声明并保留升级前副本。

## 已知问题与验证边界

- 自动记忆整理可能因每日配额耗尽而暂停，部分模型可能返回空正文。这两项尚未修复；旧记忆可见和召回通过不代表自动整理持续写入已经验收。
- 本地性能阶段测试不能代替整轮QQ延迟保证；上游模型、网络与平台回执仍会影响等待时间。
- 本轮测试使用本地模型和协议替身，没有全面验收真实QQ风控、收费模型兼容性与长期部署。源码、前端和发行成品的实际检查以随附`TEST_REPORT.md`为准。

本轮最近完整回归1909项通过、3项跳过；发行专项74项通过。Windows安装、登录、模型/QQ协议替身、直接更新和失败回滚均已检查；详细范围见随附测试报告。

完整变化见随附`RELEASE_NOTES.md`，使用方法见`docs/USER_GUIDE.md`。反馈请提交[Issue](https://github.com/iownmmiku/mikubot/issues)，附版本、部署方式、复现步骤与脱敏日志，不要包含密钥、管理令牌或私人聊天内容。
