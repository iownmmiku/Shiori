# Shiori character art

Shiori's persona, 佐藤栞, drawn from the character sheets supplied by the project owner (front/back turnaround, half-body portrait, expressions, belongings). These files are cut-outs of that art for the web console; they are not generated by code.

- `portrait.png`: half-body portrait with the iced americano (transparent background). Sign-in page.
- `stand.png`: full-body front view. Quick start.
- `chibi-quiet.png`, `chibi-pout.png`, `chibi-angry.png`: small expressions for empty lists, the chat welcome and load errors.
- `coffee.png`: her iced americano, used as a small accent.
- `avatar.jpg`: face crop on a cream circle background, used as the assistant's chat avatar.

Palette taken from the same sheets: chestnut hair `#8c5b4c`, deep plum-navy blazer `#3a3446`, cream paper `#f8f1ea`, plaid coral `#c4493f`, amber eyes `#b87a4b`.

The application icon (`../brand/`) is unchanged.
