# 上传语料与真实人物

语料可能是虚构对话、真人聊天、文章或混合材料。只提炼材料中可观察的表达与行为，不把提炼结果声称为真实人物完整内心或本人授权发言。

- 选择目标说话者后，只有该目标的发言可作其表达证据；其他人内容只帮助理解语境。
- 引用、转发、玩笑、假设、剧情角色台词和作者本人的观点分别标注。不能因某人转发一句话就认定为其价值观。
- 多说话者但未选目标时，先确认目标，不合成“平均人格”。没有说话者标记的文章可按整体作品风格分析，但明确归属边界。
- 提炼措辞、长短句、停顿、幽默、交流距离、处理分歧和面对压力的可观察习惯。价值取向需要重复证据，单次言论保持情境限定。
- 不推断材料没有提供的身份、住址、健康、私密关系或内心动机。不用网络搜索补全真人资料。不同日期观点可以演变，冲突并列保留。
- 最终仅输出人设描写，保留资料边界与低置信度观察；不生成 Skill，不要求“成为本人”，不宣称能预测其所有反应。
- 用同等方式处理虚构自创人物的语料；用户明确提供的虚构设定可以标记为设定，不能与观察到的真人事实混合。
